# Fittracker – Beta test feedback

Collected 2026-10-08. Nothing fixed yet.

## Bugs / issues
- [ ] Some buttons only respond when tapping the button text, not the whole button
- [ ] Food search: suspect not all matching foods are loaded into the results
- [ ] Create new exercise: text in the free-text input fields isn't visible, hard to know what to enter
- [ ] Can't set a default rest time between sets

## UX / feature ideas
- [ ] Logging a saved meal: show it as one row in the food log, components in an accordion
- [ ] Logged-food view: each meal as a card with highlights (kcal + macros); tap card → new view with the meal's rows
  - Note: overlaps with the accordion idea above, pick one pattern
- [ ] Remove the redundant "+" in the "Log food" and "New routine" buttons
- [ ] Exercises that can be done unilateral (one arm/leg) or bilateral need improvement — **research + plan first**
- [ ] Notifications: remind when a meal is missing, excluding snacks (e.g. breakfast + lunch logged, no dinner → reminder)
  - Open question: what time should "missing dinner" trigger?
- [ ] Default gallery of training programs — **research UX + which programs first**
- [ ] Create custom exercise directly from "Add exercise" during an ongoing workout
